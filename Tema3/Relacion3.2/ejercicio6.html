JavaScript es un lenguaje de programación que se ejecuta en el navegador y permite crear páginas web interactivas.

Los arrays son estructuras que almacenan varios valores en una sola variable, y se recorren con bucles.

Git es un sistema de control de versiones que permite trabajar en equipo usando ramas como main y develop.
